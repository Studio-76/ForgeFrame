# ForgeFrame Frontend

React 19 + TypeScript 5.9 SPA — the operator interface.

See the [main README](../README.md) for project overview, setup, and development.

## Quick Reference

```bash
npm install          # Install dependencies
npm run dev          # Start Vite dev server
npm run typecheck    # TypeScript type check
npm test             # Run tests
npm run build        # Production build
```
