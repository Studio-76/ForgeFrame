# ForgeFrame Frontend Cleanup Prompt-Paket

Dieses Paket wurde aus dem hochgeladenen ForgeFrame-ZIP und ergänzend aus dem Zielbild V9 abgeleitet. Jeder Prompt ist als harter Codex-CLI-Auftrag formuliert.

## Wichtigste Gesamtbewertung

Das Zielbild ist in der Modulbreite stark, aber für die Frontend-Umsetzung pro Seite zu unscharf. Es benennt Pflichtmodule und Zustände, definiert aber selten konkrete Bedienabläufe pro Seite. Die aktuelle UI hat deshalb viele korrekte Begriffe, aber zu wenig Produktführung. Die Prompts erzwingen pro Seite: klare Primärfunktion, echte API-/Runtime-Wahrheit, reduzierte Diagnoseflächen und konkrete Akzeptanzkriterien.
